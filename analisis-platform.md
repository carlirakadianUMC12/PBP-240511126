# Analisis Komparatif Platform: Web, Desktop, dan Mobile

## Tabel Perbandingan

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| **Bahasa utama** | HTML, CSS, JavaScript | C++, C#, Java, Python | Kotlin (Android), Swift (iOS), Dart (Flutter) |
| **Arsitektur** | Client-server; browser mengirim request ke server | Berjalan lokal di OS, mengakses sumber daya perangkat | Berjalan di OS mobile (sandbox), terhubung ke backend via API |
| **Cara distribusi** | Hosting dan diakses lewat URL | Installer atau toko aplikasi desktop | Google Play Store dan Apple App Store |
| **Keunggulan** | Tanpa instalasi, lintas perangkat, update terpusat | Performa tinggi, akses penuh ke perangkat, bisa offline | Akses sensor (kamera, GPS), notifikasi push, mudah dibawa |
| **Keterbatasan** | Butuh internet, akses perangkat keras terbatas | Harus diinstal, sering terikat satu OS | Aturan toko aplikasi, fragmentasi perangkat |
| **Contoh aplikasi** | Google Docs, Tokopedia web | Microsoft Word, Visual Studio Code | WhatsApp, Gojek |

## Refleksi

1. **Platform yang paling menarik untuk dipelajari:**
   Platform yang paling menarik bagi saya adalah web. Alasan pertama, web mudah dipahami. Untuk memulai, saya hanya perlu browser dan text editor. Saya tidak perlu menginstal banyak aplikasi yang rumit, jadi saya bisa langsung belajar. Alasan kedua, hasil kode langsung terlihat di browser. Saat saya menulis HTML, CSS, atau JavaScript, saya bisa segera melihat hasilnya. Jika ada yang salah, saya langsung tahu dan bisa memperbaikinya. Cara belajar seperti ini terasa menyenangkan dan membuat saya tidak mudah menyerah. Saya jadi lebih semangat dan percaya diri. Alasan ketiga, materi belajarnya banyak dan gratis. Saya bisa membaca dokumentasi seperti MDN Web Docs, menonton tutorial, atau bertanya di forum. Jika saya bingung, biasanya sudah ada penjelasan dan contoh kodenya. Selain itu, web bisa dibuka di berbagai perangkat, sehingga hasil kerja saya mudah dibagikan ke orang lain. Karena alasan-alasan tersebut, web adalah pilihan terbaik bagi saya untuk memulai belajar pemrograman.

2. **Tantangan terbesar saat setup environment:**
   Tantangan terbesar saat menyiapkan environment bagi saya adalah error. Ada tiga hal yang paling sulit: perintah npm install, menyiapkan database, dan mengatur file konfigurasi. Pada npm install, error sering muncul karena versi Node.js tidak cocok dengan proyek. Pesan errornya juga panjang, sehingga saya bingung mencari penyebabnya. Pada database, saya harus memasang dan menjalankan program seperti MySQL, lalu membuat database baru. Saya juga harus mengisi nama pengguna dan kata sandi dengan benar. Kesalahan kecil saja bisa membuat aplikasi gagal terhubung. Pada file konfigurasi seperti .env, saya harus mengisi data dengan tepat, misalnya alamat database dan nomor port. Jika ada salah ketik atau port sedang dipakai aplikasi lain, aplikasi tidak bisa berjalan. Hal ini sering membuat saya merasa lelah dan ingin berhenti. Masalah ini membuat waktu belajar saya terbuang karena penyebabnya tidak selalu jelas. Karena itu, bagi pemula seperti saya, tahap setup adalah bagian yang paling menguji kesabaran.

3. **Rencana mengatasi tantangan tersebut:**
   Untuk mengatasi tantangan tersebut, saya punya rencana sederhana. Pertama, sebelum mulai, saya akan mengecek spesifikasi laptop, seperti RAM dan sisa penyimpanan. Saya juga akan mencatat versi aplikasi yang dibutuhkan dari dokumentasi resmi, lalu mengunduh file besar saat sinyal sedang bagus. Kedua, untuk error npm install, saya akan memakai Node.js versi LTS dan membaca pesan error dari baris paling atas. Ketiga, untuk database dan file konfigurasi, saya akan mengikuti petunjuk di README atau dokumentasi resmi langkah demi langkah. Setiap selesai satu langkah, saya akan mengujinya dulu sebelum lanjut. Keempat, saya akan mencatat langkah yang berhasil di file SETUP.md, supaya bisa dipakai lagi jika masalah yang sama muncul. Kelima, jika saya buntu lebih dari 30 menit, saya akan mencari jawaban di forum atau bertanya kepada teman atau dosen. Saya tidak akan malu bertanya, karena itu bagian dari proses belajar. Dengan rencana ini, saya berharap proses setup lebih cepat dan waktu belajar tidak terbuang.
